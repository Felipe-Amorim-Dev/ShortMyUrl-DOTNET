## 📖 About

ASP.NET Core 8 API generating short identifiers, storing links in MongoDB and redirecting through GET /r/{codigo}. Includes Docker Compose and Swagger.

## ✨ Features

- Create and query short URLs
- Delete stored links
- Redirect to the original URL

<a id="como-rodar"></a>
## 🚀 Running locally

```bash
git clone https://github.com/Felipe-Amorim-Dev/ShortMyUrl-DOTNET.git
cd ShortMyUrl-DOTNET
docker compose up --build
```

Swagger: http://localhost:8081/swagger
